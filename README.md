# 🕹️ Arduino Joystick Controlled Servo
📝 Description
This project explores the functionality of an analog joystick by building an interactive circuit using an Arduino Uno. The main goal of this project is to understand how a joystick works (reading analog values from its internal potentiometers on the X and Y axes) and how a microcontroller translates these inputs to control a physical actuator.

By taking the analog signals from the joystick and mathematically combining them, the Arduino maps these values into specific angles (0° to 180°) to steer a servo motor in real-time. It is a great hands-on introduction to working with analog sensors, mixed-input logic, and mechanical components.

## 🛠️ Languages and Utilities Used
- **Arduino IDE** (Integrated Development Environment)
- **C/C++** (Arduino Programming Language)

## 🖥️ Environments Used
- **Windows 11**

## 🧰 Hardware Components Used
- **1x** Arduino Uno Board
- **1x** Analog Joystick Module
- **1x** Servo Motor (e.g., SG90)
- Male-to-Male and Male-to-Female Jumper Wires
